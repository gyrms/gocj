# 11724 연결 요소의 개수 — 해설

---

## 1. 한 줄 요약

> **2606의 `dfs()` 를 그대로 쓰되, 바깥에 for문을 하나 씌운다.**

`dfs(i)` 한 번을 부르면 **i가 속한 덩어리 전체**가 `visited = true` 가 된다.
그러니 아직 방문 안 된 정점을 만날 때마다 `dfs` 를 부르고, **부른 횟수를 세면 그게 덩어리 개수.**

---

## 2. 완성 코드 (DFS)

```java
import java.io.*;
import java.util.*;

public class Main {
    static List<Integer>[] graph;
    static boolean[] visited;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        // ⚠️ 2606과 다른 점 ①: N M 이 한 줄에 같이 온다
        StringTokenizer st = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st.nextToken());
        int m = Integer.parseInt(st.nextToken());

        graph = new ArrayList[n + 1];
        for (int i = 1; i <= n; i++) graph[i] = new ArrayList<>();
        visited = new boolean[n + 1];

        for (int i = 0; i < m; i++) {
            st = new StringTokenizer(br.readLine());
            int a = Integer.parseInt(st.nextToken());
            int b = Integer.parseInt(st.nextToken());
            graph[a].add(b);
            graph[b].add(a);
        }

        // ⚠️ 2606과 다른 점 ②: 모든 정점을 시작점으로 시도
        int count = 0;
        for (int i = 1; i <= n; i++) {
            if (!visited[i]) {
                dfs(i);
                count++;
            }
        }
        System.out.println(count);
    }

    // 2606에서 쓴 것과 완전히 동일
    static void dfs(int now) {
        visited[now] = true;
        for (int next : graph[now]) {
            if (!visited[next]) dfs(next);
        }
    }
}
```

## 3. 예제 1 실행 흐름

입력
```
6 5
1 2
2 5
5 1
3 4
4 6
```

완성된 그래프
```
graph[1] = [2, 5]
graph[2] = [1, 5]
graph[3] = [4]
graph[4] = [3, 6]
graph[5] = [2, 1]
graph[6] = [4]
```

바깥 for문이 도는 과정

| i | visited[i] | 동작 | 방문 상태 | count |
|---|---|---|---|---|
| 1 | false | **dfs(1)** → 1,2,5 방문 | `1 2 _ _ 5 _` | **1** |
| 2 | true | 건너뜀 | | 1 |
| 3 | false | **dfs(3)** → 3,4,6 방문 | `1 2 3 4 5 6` | **2** |
| 4 | true | 건너뜀 | | 2 |
| 5 | true | 건너뜀 | | 2 |
| 6 | true | 건너뜀 | | 2 |

**답 = 2**

### 여기서 볼 것

- `dfs(1)` **한 번**에 1, 2, 5가 **전부** 방문 처리된다 → 그래서 i=2, i=5 는 건너뛰어진다
- 건너뛰는 게 정상이고, 그게 "이미 센 덩어리"라는 뜻이다
- `count++` 는 **새 덩어리를 발견했을 때만** 올라간다

## 4. BFS로 바꾸면

`dfs(i)` 자리에 `bfs(i)` 를 넣기만 하면 된다. 바깥 for문은 그대로.

```java
for (int i = 1; i <= n; i++) {
    if (!visited[i]) {
        bfs(i);        // ← 이것만 교체
        count++;
    }
}

static void bfs(int start) {
    Queue<Integer> q = new ArrayDeque<>();
    visited[start] = true;
    q.offer(start);

    while (!q.isEmpty()) {
        int now = q.poll();
        for (int next : graph[now]) {
            if (!visited[next]) {
                visited[next] = true;
                q.offer(next);
            }
        }
    }
}
```

**이 문제는 "최단 거리"를 묻지 않으므로 DFS/BFS 둘 다 정답.**

## 5. 2606 → 11724 변화 정리

```java
// 2606
dfs(1);
System.out.println(count);        // count 는 dfs 안에서 증가

// 11724
int count = 0;
for (int i = 1; i <= n; i++) {
    if (!visited[i]) { dfs(i); count++; }   // count 는 바깥에서 증가
}
System.out.println(count);
```

**`count` 를 세는 위치가 안에서 밖으로 나온 것**이 가장 큰 차이다.

- 2606: `count` = 방문한 **노드 수** → dfs 안에서 증가
- 11724: `count` = 덩어리 수 = **dfs 호출 횟수** → 바깥에서 증가

## 6. 체크리스트

- [ ] 첫 줄을 `StringTokenizer` 로 쪼개서 N, M 둘 다 읽었나
- [ ] `graph[i] = new ArrayList<>()` for문 넣었나
- [ ] 양방향 `add` 2줄 넣었나
- [ ] 바깥 for문에서 `if (!visited[i])` 로 걸렀나
- [ ] `count++` 를 바깥 for문에 두었나 (dfs 안이 아니라)
- [ ] `input.txt` → 2,  `input2.txt` → 1 나오나

다 되면 **BFS 버전으로 한 번 더.** 바깥 for문은 그대로 두고 `dfs` 만 `bfs` 로 바꾸면 된다.
