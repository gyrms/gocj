## 1. 이 문제가 묻는 것

> **1번과 (직접이든 간접이든) 이어져 있는 컴퓨터가 몇 대냐?**

"최소 몇 번 만에" 같은 걸 안 묻는다 → **DFS/BFS 둘 다 정답.**
연결된 덩어리 하나의 크기를 세는 전형적인 문제.

---

## 2. 예제로 그래프 만들어보기

입력
```
7        ← 컴퓨터 7대
6        ← 연결 6쌍
1 2
2 3
1 5
5 2
5 6
4 7
```

양방향으로 넣으면 이렇게 완성된다.

```
graph[1] = [2, 5]
graph[2] = [1, 3, 5]
graph[3] = [2]
graph[4] = [7]        ← 1번과 이어지지 않은 섬
graph[5] = [1, 2, 6]
graph[6] = [5]
graph[7] = [4]        ← 1번과 이어지지 않은 섬
```

그림으로 보면

```
    1 ─── 2 ─── 3
    │     │
    └──── 5
          │
          6              4 ─── 7
```

## 3. 완성 코드 (DFS)

```java
import java.io.*;
import java.util.*;

public class Main {

    static List<Integer>[] graph;
    static boolean[] visited;
    static int count = 0;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine().trim());   // 컴퓨터 수
        int m = Integer.parseInt(br.readLine().trim());   // 연결 쌍 수

        graph = new ArrayList[n + 1];                     // 번호가 1부터 → n+1
        for (int i = 1; i <= n; i++) {
            graph[i] = new ArrayList<>();                 // ⚠️ 이게 없으면 NPE
        }
        visited = new boolean[n + 1];

        for (int i = 0; i < m; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            int a = Integer.parseInt(st.nextToken());
            int b = Integer.parseInt(st.nextToken());
            graph[a].add(b);                              // ⚠️ 양방향
            graph[b].add(a);
        }

        dfs(1);
        System.out.println(count);
    }

    static void dfs(int now) {
        visited[now] = true;                  // ① 지금 위치 방문 처리

        for (int next : graph[now]) {         // ② 이웃을 하나씩
            if (!visited[next]) {             // ③ 아직 안 갔으면
                count++;                      //    감염 +1
                dfs(next);                    //    들어간다
            }
        }
    }
}
```

### 줄별 해설

| 코드 | 의미 |
|---|---|
| `new ArrayList[n + 1]` | 번호가 1~n이라 0번 자리는 버리고 `graph[1]`부터 쓴다 |
| `graph[i] = new ArrayList<>()` | **배열은 칸만 만들고 안은 null.** 리스트를 직접 채워야 한다 |
| `graph[a].add(b); graph[b].add(a);` | "1과 2가 연결"은 **양쪽 모두에서** 갈 수 있다는 뜻 |
| `visited[now] = true` | 무한 반복 방지. 없으면 1→2→1→2… |
| `count++` **가 `dfs(next)` 앞에 있는 이유** | 여기서 세면 **1번은 절대 안 세어진다.** `dfs()` 맨 위에서 세면 1번까지 포함돼 답이 5가 된다 |

## 4. 실제 실행 흐름 (예제 기준)

```
1번 방문  (이웃 [2, 5])
 ├ 2번 감염! count=1 → 들어감
   2번 방문  (이웃 [1, 3, 5])
    ├ 1번 이미 감염됨 → 건너뜀
    ├ 3번 감염! count=2 → 들어감
      3번 방문  (이웃 [2])
       ├ 2번 이미 감염됨 → 건너뜀
       └ 3번 끝, 되돌아감
    ├ 5번 감염! count=3 → 들어감
      5번 방문  (이웃 [1, 2, 6])
       ├ 1번 이미 감염됨 → 건너뜀
       ├ 2번 이미 감염됨 → 건너뜀
       ├ 6번 감염! count=4 → 들어감
         6번 방문  (이웃 [5])
          ├ 5번 이미 감염됨 → 건너뜀
          └ 6번 끝, 되돌아감
       └ 5번 끝, 되돌아감
    └ 2번 끝, 되돌아감
 ├ 5번 이미 감염됨 → 건너뜀
 └ 1번 끝, 되돌아감

최종 count = 4
```

### 여기서 볼 것 3가지

1. **들여쓰기가 깊어지는 게 "파고드는 것"** — 1→2→3까지 들어갔다가 3번에서 막히니 되돌아온다.
2. **되돌아온 뒤 남은 이웃을 마저 본다** — 2번으로 돌아와서 아직 안 본 5번으로 간다.
3. **4번·7번은 아예 등장하지 않는다** — 1번과 이어진 길이 없으니 `dfs`가 닿질 못한다. 그래서 답이 6이 아니라 **4**.

## 5. 같은 문제를 BFS로

```java
static int bfs(int start) {
    Queue<Integer> q = new ArrayDeque<>();
    visited[start] = true;
    q.offer(start);
    int count = 0;

    while (!q.isEmpty()) {
        int now = q.poll();
        for (int next : graph[now]) {
            if (!visited[next]) {
                visited[next] = true;    // ⚠️ 넣을 때 바로 표시
                count++;
                q.offer(next);
            }
        }
    }
    return count;
}
```

**바뀐 건 `dfs(next)` → `q.offer(next)` 뿐이다.**

큐 변화
```
[1] → 1 꺼냄 → [2, 5]
    → 2 꺼냄 → [5, 3]
    → 5 꺼냄 → [3, 6]
    → 3 꺼냄 → [6]
    → 6 꺼냄 → []
```
방문 순서 **1 → 2 → 5 → 3 → 6**, 답은 똑같이 **4**.

DFS는 `1→2→3→5→6`, BFS는 `1→2→5→3→6`.
**순서는 다르지만 "닿는 집합"은 같다.** 그래서 개수만 세는 이 문제는 둘 다 맞다.

## 6. 내일 직접 풀 때 체크리스트

- [ ] `graph[i] = new ArrayList<>()` for문 넣었나 (NPE 1순위)
- [ ] 연결을 **양방향** 2줄로 넣었나
- [ ] `count++` 위치가 맞나 (답이 5면 1번을 같이 센 것)
- [ ] 배열 크기를 `n + 1`로 잡았나
- [ ] 답 `4` 나오나 → `javac Main.java && java Main < input.txt`

다 되면 **BFS로 한 번 더** 짜볼 것. 큐로 바꾸는 것만으로 되는 걸 손으로 확인하면 둘의 차이가 확실히 박힌다.
