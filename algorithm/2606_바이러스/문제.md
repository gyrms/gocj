# 백준 2606 — 바이러스

🔗 https://www.acmicpc.net/problem/2606
`Silver 3` · `DFS/BFS` · 그래프형

---

## 문제

신종 바이러스인 **웜 바이러스**는 네트워크를 통해 전파된다.
한 컴퓨터가 웜 바이러스에 걸리면, 그 컴퓨터와 네트워크상에서 **연결되어 있는 모든 컴퓨터**는 웜 바이러스에 걸리게 된다.

예를 들어 7대의 컴퓨터가 아래처럼 연결되어 있다고 하자.

```
        1 ─── 2 ─── 3
        │     │
        └──── 5
              │
              6            4 ─── 7      ← 4,7은 따로 떨어진 섬
```

1번 컴퓨터가 웜 바이러스에 걸리면
→ 2번, 5번을 거쳐 3번, 6번까지 전파되어 **2, 3, 5, 6 네 대**가 걸린다.
→ 4번과 7번은 1번과 연결되어 있지 않으므로 **영향을 받지 않는다.**

1번 컴퓨터가 웜 바이러스에 걸렸을 때,
**1번 컴퓨터를 통해 웜 바이러스에 걸리게 되는 컴퓨터의 수**를 출력하시오.

---

## 입력

```
첫째 줄   컴퓨터의 수 N        (100 이하, 번호는 1번부터)
둘째 줄   연결된 컴퓨터 쌍의 수 M
이후 M줄  직접 연결된 두 컴퓨터의 번호
```

## 출력

1번 컴퓨터를 통해 감염되는 컴퓨터의 수.
**⚠️ 1번 자신은 포함하지 않는다.**

---

## 예제

**입력** (`input.txt`)
```
7
6
1 2
2 3
1 5
5 2
5 6
4 7
```

**출력**
```
4
```

## 풀이 힌트

### 단계별로 쪼개기

| 단계 | 할 일 |
|---|---|
| ① | 입력 읽기 — 첫 두 줄은 각각 숫자 하나 |
| ② | 그래프 만들기 — 배열 + 각 칸에 리스트, **양방향**으로 넣을 것 |
| ③ | 1번에서 DFS 시작 |
| ④ | 세서 출력 — **1번 자신은 빼고** |

### 자주 하는 실수

1. **배열만 만들고 리스트를 안 넣음** → `NullPointerException`
   ```java
   graph = new ArrayList[n + 1];       // 이것만 하면 안은 전부 null
   for (int i = 1; i <= n; i++)
       graph[i] = new ArrayList<>();   // 이게 꼭 필요
   ```

2. **단방향으로만 넣음** → 답이 틀림
   ```java
   graph[a].add(b);
   graph[b].add(a);   // 이 줄을 빼먹기 쉬움
   ```

3. **1번을 같이 세어버림** → 답이 5로 나옴
   - `count++` 를 `dfs()` 맨 위에 두면 1번도 세어진다
   - 해결 ⓐ: `dfs(next)` 호출 직전에 `count++`
   - 해결 ⓑ: 맨 위에서 세고 마지막에 `count - 1` 출력

4. **`n + 1` 크기로 안 만듦** → 번호가 1부터라 `graph[n]` 접근 시 터짐

### 생각해볼 것

- 이 문제는 **"최단 거리"를 묻지 않는다.** → DFS/BFS 둘 다 정답
- 첫 문제이므로 **DFS 재귀**로 짜보는 걸 추천 (코드가 짧아 구조가 눈에 들어옴)
- 다 풀었으면 **같은 문제를 BFS로 다시** 짜보면 둘의 차이가 확실히 잡힌다
